# Планы интеграционного и системного тестирования Placy

Статус: **черновик, преподавателем не утверждён**. Это перечень предлагаемых сценариев, не результатов выполнения. Реализовывать интеграционные и E2E тесты только после утверждения. Столбец «доступность» отражает статический осмотр исходников на 5fc48b3; работоспособность приложения не подтверждена.

Общее окружение: Android-эмулятор API 26 и выше, отдельный тестовый стенд, заранее подготовленные данные, без обращения к рабочим данным. Сценарии с отсутствующими возможностями включены как кандидаты для обсуждения, не как обещание их реализации в рамках тестирования.

## Интеграционные сценарии — кандидаты на утверждение

Для каждого сценария устанавливается исходное состояние, выполняется действие и проверяется результат на границе взаимодействующих компонентов. Внешние зависимости подменяются управляемыми сервисами; негативные случаи помечены «негативный».

| ID | ФТ | Сценарий и ожидаемый результат | Доступность |
|---|---|---|---|
| INT-01 | F_Map_04 | Клиент запрашивает метки; ответ с координатами передаётся экрану карты. | Частично: клиент запрашивает все метки, фильтрация видимой области не обнаружена. |
| INT-02 | F_Map_05 | Данные публикации преобразуются в метку в соответствующей координате. | Частично; требуется тестируемая граница карты. |
| INT-03 | F_Post_04 | Выбор изображения передаёт идентификатор загрузчику фотографии. | Частично; карточка не обнаружена. |
| INT-04 | F_Post_07 | Отмена съёмки возвращает на карту без отправки публикации. | Проверить фактическую навигацию на стенде. |
| INT-05 | F_Post_08 | После снимка загрузка изображения и сохранение метки связываются идентификатором. | Требует проверки фактической реализации. |
| INT-06 | F_Post_01 | Негативный: недоступная геопозиция приводит к предусмотренному выбору пользователя. | Диалог выбора не обнаружен. |
| INT-07 | F_Post_02 | Негативный: отсутствие разрешения вызывает системный запрос. | Проверить на эмуляторе; требуется управляемая геопозиция. |
| INT-08 | F_Auth_05 | Негативный: неверные учётные данные дают предусмотренное сообщение. | Авторизация не обнаружена. |
| INT-09 | F_Mod_03 | Негативный: отклонённая публикация отсутствует в данных карты. | Модерация и сервер не обнаружены. |
| INT-10 | F_Mod_05 | Негативный: исчерпание квоты останавливает съёмку и показывает сообщение. | Квота не обнаружена. |

## Системные E2E-сценарии — кандидаты на утверждение

Сценарии выполняются через установленное приложение как пользовательские действия с проверкой видимого результата. Тестовый сервер должен предоставлять управляемые данные и хранить результат; подмена внутренних функций UI не делает сценарий E2E.

| ID | ФТ | Действие и ожидаемый результат | Доступность |
|---|---|---|---|
| E2E-01 | F_Map_01 | Запустить приложение — открывается карта. | Карта присутствует; запуск не проверен. |
| E2E-02 | F_Auth_01 | Без входа открыть карту и карточку публикации. | Карта присутствует, карточка не обнаружена. |
| E2E-03 | F_Map_02 | Перетащить карту — видимая область перемещается. | Требуется работающий MapKit. |
| E2E-04 | F_Map_03 | Изменить масштаб жестом — масштаб карты меняется. | Требуется работающий MapKit. |
| E2E-05 | F_Map_04 | Открыть карту с подготовленными публикациями — видны публикации области. | Фильтрация области не обнаружена. |
| E2E-06 | F_Map_05 | Открыть карту с известной точкой — красный пин указывает на неё. | Ресурс пина используется; проверка не проводилась. |
| E2E-07 | F_Map_06 | Открыть карту — кнопка камеры находится внизу по центру. | Разметка присутствует. |
| E2E-08 | F_Post_03 | Нажать метку — открывается карточка поверх карты. | Вместо карточки код открывает просмотр изображения. |
| E2E-09 | F_Post_04 | Нажать фото в карточке — открывается полный экран. | Карточка не обнаружена. |
| E2E-10 | F_Post_05 | Нажать вне карточки — карточка закрывается. | Карточка не обнаружена. |
| E2E-11 | F_Post_06 | Нажать системную кнопку «Назад» в карточке — карточка закрывается. | Карточка не обнаружена. |
| E2E-12 | F_View_02 | Нажать полноэкранное фото — вернуться к карте. | Обработчик закрытия присутствует. |
| E2E-13 | F_View_03 | Переместить карту, открыть и закрыть фото — положение и масштаб сохраняются. | Требует проверки на эмуляторе. |
| E2E-14 | F_Post_07 | Отменить съёмку — открывается карта, публикация не создаётся. | Требует проверки фактической навигации. |
| E2E-15 | F_Auth_02 | Без входа нажать «Камера» — открывается вход. | Авторизация и экран входа не обнаружены. |

При утверждении исключить или отдельно согласовать недоступные сценарии; наличие 15 кандидатов не означает 15 реализуемых и проходящих E2E тестов. НФТ производительности и нагрузки не подтверждаются данными сценариями.
