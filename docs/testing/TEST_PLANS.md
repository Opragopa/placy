# Планы интеграционного и системного тестирования Placy

Статус: **утверждение преподавателем подтверждено пользователем 29.10.2026**; документ не является результатом выполнения тестов. Столбец «доступность» отражает статический осмотр исходников на 5fc48b3; работоспособность приложения не подтверждена.

Общее окружение: Android-эмулятор API 26 и выше, отдельный тестовый стенд, заранее подготовленные данные, без обращения к рабочим данным. Сценарии с отсутствующими возможностями включены как кандидаты для обсуждения, не как обещание их реализации в рамках тестирования.

## Интеграционные сценарии на реализованной функциональности

Пользователь подтвердил согласование преподавателем замены прежних интеграционных сценариев набором на реализованной функциональности. Ниже — новая редакция плана; она не подтверждает реализацию авторизации, модерации и фильтрации карты. Все 10 сценариев выполняются реальными клиентами Ktor CIO и управляемым локальным HTTP-сервером MockWebServer. Граница проверки указана явно: это интеграционные проверки компонентов и HTTP-контракта, а не сквозные проверки интерфейса или рабочего сервера. Негативных сценариев — не менее шести.

| ID | Связь с ФТ | Сценарий и ожидаемый результат | Тест `HttpClientIntegrationTest` |
|---|---|---|---|
| INT-01 | F_Map_04, частично | API возвращает метку: клиент десериализует идентификатор и координаты и запрашивает `/geomarks`. Фильтрация области и показ на карте не проверяются. | `loadsMarksOverHttp` |
| INT-02 | F_Map_04, частично | API возвращает пустой список: клиент получает пустую коллекцию и выполняет запрос к меткам. | `emptyMapResponseHasNoMarks` |
| INT-03 | F_Post_04, частично | Клиент хранилища запрашивает фотографию по пути и возвращает полученные байты. Отображение UI не проверяется. | `downloadsPhotoOverHttp` |
| INT-04 | F_Post_04, частично; негативный | Хранилище отвечает 404: клиент сообщает об отсутствии фотографии. | `missingPhotoIsReportedByClient` |
| INT-05 | F_Post_08, частично | Публикатор отправляет фото и метаданные через два HTTP-клиента с одним идентификатором и нужными координатами; проверяются порядок, путь и содержимое запросов. Уникальность и работа камеры отдельно не проверяются. | `imageAndMetadataUseSameIdentifier` |
| INT-06 | F_Post_08, частично; негативный | Ошибка загрузки фото: публикатор возвращает ошибку и не отправляет метаданные. | `failedUploadStopsPublicationBeforeMetadataRequest` |
| INT-07 | F_Post_08, частично; негативный | Фото загружено, но сервер метаданных отвечает ошибкой: публикатор возвращает ошибку сохранения. | `failedMetadataIsNotReportedAsPublicationSuccess` |
| INT-08 | F_Post_08, частично; негативный | Хранилище отвечает 401 при загрузке: клиент сообщает об ошибке. | `photoUploadRejectsUnauthorizedResponse` |
| INT-09 | F_Map_04, частично; негативный | API возвращает метаданные без обязательной координаты: клиент не создаёт некорректную метку. | `invalidMetadataCannotBeDeserializedAsMark` |
| INT-10 | F_Post_08, частично; негативный | API отвечает 409 при сохранении метаданных: клиент сообщает, что сохранение не удалось. | `metadataRejectionIsReported` |

Дополнительно сохраняются две HTTP-проверки: ошибка загрузки 503 и некорректный JSON. Пустой ответ при ошибке чтения — текущее поведение клиента, а не подтверждение обработки ошибки интерфейсом.

## Системные E2E-сценарии — кандидаты на утверждение

Сценарии выполняются через установленное приложение как пользовательские действия с проверкой видимого результата. Тестовый сервер должен предоставлять управляемые данные и хранить результат; подмена внутренних функций UI не делает сценарий E2E.

| ID | ФТ | Действие и ожидаемый результат | Доступность |
|---|---|---|---|
| E2E-01 | F_Map_01 | Запустить приложение — открывается карта. | Карта присутствует; запуск не проверен. |
| E2E-02 | F_Auth_01 | Без входа открыть карту и карточку публикации. | Карта и карточка добавлены; тест ожидает эмулятора. |
| E2E-03 | F_Map_02 | Перетащить карту — видимая область перемещается. | Требуется работающий MapKit. |
| E2E-04 | F_Map_03 | Изменить масштаб жестом — масштаб карты меняется. | Требуется работающий MapKit. |
| E2E-05 | F_Map_04 | Открыть карту с подготовленными публикациями — видны публикации области. | Фильтрация области не обнаружена. |
| E2E-06 | F_Map_05 | Открыть карту с известной точкой — красный пин указывает на неё. | Ресурс пина используется; проверка не проводилась. |
| E2E-07 | F_Map_06 | Открыть карту — кнопка камеры находится внизу по центру. | Разметка присутствует. |
| E2E-08 | F_Post_03 | Нажать метку — открывается карточка поверх карты. | Карточка добавлена; тест ожидает эмулятора. |
| E2E-09 | F_Post_04 | Нажать фото в карточке — открывается полный экран. | Карточка добавлена; тест ожидает эмулятора. |
| E2E-10 | F_Post_05 | Нажать вне карточки — карточка закрывается. | Карточка добавлена; тест ожидает эмулятора. |
| E2E-11 | F_Post_06 | Нажать системную кнопку «Назад» в карточке — карточка закрывается. | Карточка добавлена; тест ожидает эмулятора. |
| E2E-12 | F_View_02 | Нажать полноэкранное фото — вернуться к карте. | Обработчик закрытия присутствует. |

| E2E-15 | F_Auth_02 | Без входа нажать «Камера» — открывается вход. | Авторизация и экран входа не обнаружены. |

При утверждении исключить или отдельно согласовать недоступные сценарии; наличие 15 кандидатов не означает 15 реализуемых и проходящих E2E тестов. НФТ производительности и нагрузки не подтверждаются данными сценариями.
