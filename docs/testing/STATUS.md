На коммите ab56fdb в CI прошли 27 unit-тестов приложения и 6 HTTP-интеграционных проверок; шаблонная арифметическая проверка впоследствии удалена и в 27 не включена. JaCoCo показал 5 покрытых из 94 ветвей (около 5,3%); в этот расчёт вошёл код интерфейса. Цель 80 содержательных unit-тестов не достигнута; распределение 20 на человека следует делать только по реальным проверкам и с учётом фактического авторства.

## Окружение

Для реального запуска карты нужны Android SDK, эмулятор и действующий ключ MapKit. `apikey.properties` остаётся локальным и не коммитится. Без файла ключей используются пустой ключ карты и недоступный домен example.invalid для Nextcloud; это допускает тестовую конфигурацию без секретов, но не делает работающим MapKit. Не использовать реальные учётные данные и внешние пользовательские данные в CI.

## Первые E2E-тесты

Добавлены два инструментальных теста запуска настоящего `MainActivity`: наличие карты (E2E-01) и кнопки камеры (E2E-07). Они не проверены на эмуляторе. Тесты до запуска приложения требуют изолированные API и хранилище на `10.0.2.2` и непустой тестовый ключ MapKit. Для тестовой сборки нужно задать `API_URL="http://10.0.2.2:порт"`, `SERVER_URL="http://10.0.2.2:порт"` и `MAPKIT_API_KEY` в локальном `apikey.properties` в формате Kotlin-строк; файл не коммитить. Добавлены ограниченный сервер фикстур `scripts/e2e_fixture.py` и workflow `Android E2E smoke` (по pull request и вручную); для запуска в GitHub требуется secret `MAPKIT_API_KEY`. Workflow и тесты на эмуляторе ещё не проверены. Один тест проверяет видимость кнопки, но ещё не подтверждает её расположение внизу по центру.
