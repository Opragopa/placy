## Окружение

Для реального запуска карты нужны Android SDK, эмулятор и действующий ключ MapKit. `apikey.properties` остаётся локальным и не коммитится. Без файла ключей используются пустой ключ карты и недоступный домен example.invalid для Nextcloud; это допускает тестовую конфигурацию без секретов, но не делает работающим MapKit. Не использовать реальные учётные данные и внешние пользовательские данные в CI.

Добавлены шесть сценариев через настоящий `MainActivity`: карта, кнопка камеры, открытие карточки и фотографии, возврат системной кнопкой и касанием. Тесты не подтверждены прогоном на эмуляторе. Для тестовой сборки нужно задать `API_URL="http://10.0.2.2:порт"`, `SERVER_URL="http://10.0.2.2:порт"` и `MAPKIT_API_KEY` в локальном `apikey.properties` в формате Kotlin-строк; файл не коммитить. Добавлены ограниченный сервер фикстур `scripts/e2e_fixture.py` и workflow `Android E2E smoke` (по pull request и вручную); для запуска в GitHub требуется secret `MAPKIT_API_KEY`. Workflow и тесты на эмуляторе ещё не проверены. Один тест проверяет видимость кнопки, но ещё не подтверждает её расположение внизу по центру.
