## Учёт

13 существовавших проверок API и Nextcloud перенесены из инструментальных тестов в JVM unit-набор; это перенос, а не 13 новых уникальных сценариев. Дополнительно написаны проверки обработки данных, HTTP-ответов и запросов. Шаблонный тест арифметики удалён: он не проверял приложение. Остальные старые тесты требуют отдельного аудита классификации. На коммите 15cdc65 в CI прошли 82 unit-теста и 12 HTTP-интеграционных проверок, 0 пропусков и ошибок. Последний измеренный JaCoCo показал 53 покрытые из 172 ветвей (30,8%); в этот расчёт входит код интерфейса. Проверки HTTP-взаимодействий покрывают границы обновлённого плана, а не ранее задуманные сценарии с отсутствующими функциями; распределение 20 на человека следует делать только по реальным проверкам и с учётом фактического авторства.

Пользователь 29.10.2026 подтвердил утверждение тест-планов преподавателем. Недоступные сценарии остаются отмеченными; само утверждение не подтверждает реализацию соответствующих функций.

## Окружение

Для реального запуска карты нужны Android SDK, эмулятор и действующий ключ MapKit. `apikey.properties` остаётся локальным и не коммитится. Без файла ключей используются пустой ключ карты и недоступный домен example.invalid для Nextcloud; это допускает тестовую конфигурацию без секретов, но не делает работающим MapKit. Не использовать реальные учётные данные и внешние пользовательские данные в CI.
